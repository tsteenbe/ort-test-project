# Welcome

This is mock content for a static website that is generated by the `website` project. None of the
text here means anything, it only exists so that the site has more than one page.

- The build is driven by [`build.js`](../../build.js).
- Pages live in `src/content` and are written in Markdown with YAML front matter.
- The layout lives in `src/templates/page.mustache`.

## Getting started

```console
$ npm install
$ npm run build
```

The generated site ends up in `public/`.
